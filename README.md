# Business Casual

An animated, nostalgic Y2K NFC landing experience for choosing a little offline time.

## What it does

- Plays a dial-up-inspired boot sequence
- Turns the status from `ONLINE` to `LIVING LIFE` during a focus session
- Schedules and stores offline routines in the browser
- Includes a usable 10, 25, or 45 minute focus timer
- Stores visual, sound, and reduced-motion preferences locally
- Works across desktop and mobile layouts

Business Casual runs entirely in the browser. It cannot block other phone apps. The product is designed as a playful cue and an intentional timer, not an operating-system-level app blocker.

## Run locally

Serve the folder with any static web server, for example:

```sh
npx serve .
```
